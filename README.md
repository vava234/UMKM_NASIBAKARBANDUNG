# Nasi Bakar Bandung

## Menjalankan website

Website memakai server Python bawaan dan tidak memerlukan package tambahan atau API key.

1. Buka PowerShell di folder proyek.
2. Jalankan:

```powershell
python server.py
```

3. Buka `http://127.0.0.1:5500`.

Untuk pengantaran, pelanggan wajib mengisi alamat. Total yang dikirim adalah subtotal makanan; admin mengonfirmasi ongkir dan total akhir melalui WhatsApp. Ambil sendiri tetap tanpa ongkir.

Untuk penggunaan publik, jalankan server di hosting yang mendukung Python dan gunakan HTTPS. Jangan mempublikasikan server pengembangan langsung ke internet.
